# fe-dev-playbook · 前端开发实战手册

> 在线阅读：[yanyue404/fe-dev-playbook](https://yanyue404.github.io/fe-dev-playbook/)

这是一份持续进化的前端工程实践手册，沉淀日常开发中真正高频、真正有用的工具、技巧与心法。它不追求大而全，而是帮你**用对的工具，把事情一次做对**：让刚加入团队的同学快速对齐工程规范，也让资深开发者有一处可随手翻阅、可持续补充的参考。

不局限于前端，但服务于前端。

## 设计原则

1. **效率优先**：熟练使用快捷键、命令行与现代工具，把双手从重复劳动中解放出来。
2. **拥抱现代工具链**：合理选型（而非盲目追新），让 ESM、TypeScript、Vite、pnpm 等成为生产力而非负担。
3. **干净可控的开发体验**：环境配置可复现、可迁移，不在「能用就行」的别扭里凑合。
4. **沉淀可复用的经验**：把踩过的坑、验证过的方案写下来，形成团队可共享的工程心智。

## 内容地图

- **终端与 Shell**：配置高效终端，掌握日常必备命令
- **Node.js 工程环境**：版本管理（fnm/Volta/nvm）、包管理（pnpm/Corepack）、实用 CLI 模块
- **Git 协作**：分支模型、提交规范与团队协作工作流
- **VS Code 与断点调试**：打造贴合前端的编辑器，掌握高效的 debug 方法
- **Chrome / DevTools**：浏览器调试与性能分析技巧
- **TypeScript 进阶**：类型体操之外，真正落地的高级用法
- **前端实战（Fe）**：跨域、文件导出、代码规范等高频问题与方案
- **实用工具与网站**：跨平台效率工具与开发者常用站点
- **开发小贴士（Tips）**：可读性、可维护性与工程化的小而美实践

> 这不是一篇穷举所有用法的百科，而是「贵精不贵多」的经验集。需要系统学习时，请以各工具**官方文档**为准。如果它对你有帮助，欢迎点个 Star ✨，也欢迎提 Issue / PR 一起完善。
